# 纸间 · 小说创作工作台

免登录的小说创作工作台。可生成和编辑小说概要、重要提示、章节大纲与正文，支持设定卡、章节事实记忆、选段修订、版本恢复和流式草稿预览。

## 使用

新建作品后先写概要和核心冲突，再整理设定卡。生成大纲、追加章节或逐章写正文时，AI 会参考这些设定。生成结果在预览中确认后才写入正文；可停止流式输出，已收到的文字会保留为近期草稿。选中正文片段可扩写、重写、缩写或润色。替换全书大纲、删除章节、采用 AI 修订前会建立可恢复的快照。

匿名工作区由浏览器的安全 Cookie 标识。**清除 Cookie 会失去该工作区的访问凭据**，请定期导出 Markdown 备份。旧版共享作品以只读方式显示，需先复制到当前工作区再继续编辑。匿名工作区不提供跨设备同步或账号找回。

默认 DeepSeek 密钥只在服务端使用。默认模型每日限全站 30 次、每工作区 10 次；自定义模型的密钥只在页面内存中使用，刷新后需重新填写。非密钥的模型地址、名称和温度保存在浏览器本地。

## 开发

`npm run db:generate` 生成 D1 迁移；`npx tsc --noEmit` 与 `npm run build` 验证代码。数据库结构见 `db/schema.ts`，迁移按 `drizzle/` 中的编号顺序执行。Sites 发布时会应用待执行的迁移。
